# Notes Application

## Overview
This Notes Application is a Node.js command-line project created by following the Udemy **Node.js Notes App** tutorial (Sections 3–5).  

## Features
- Load and save notes from a JSON file
- Automatically create a JSON file if one does not exist
- Add new notes with a title and body
- Remove a note by title
- Remove all notes at once
- List all note titles
- Read a note by displaying its body

## Technologies Used
- Node.js
- JSON for data storage
- Command-line arguments
